## Session title

Every session in this repo gets a title in the format `<Project> · <Topic>: <short description>`, in German, for example `Privatlab · Tennis: Trainingsnotizen`. Set it with `set_session_title` as soon as the first user message shows what the work is about, and rename it if the topic changes substantially. Use the project name `Privatlab` exactly. Keep the title under 60 characters.
